# 🧮 Calculator Web App

A simple and stylish calculator built using **HTML**, **CSS**, and **JavaScript**. This project is part of _The Code School_ series and demonstrates basic DOM manipulation and event handling.

## 🚀 Live Preview

[Click here to see it live](https://calculator-cs.netlify.app/)  


## 📸 Screenshot

![Calculator Screenshot](https://github.com/Abhranil2004/Calculator/blob/general/ss.png)  

## 🛠️ Features

- Basic arithmetic operations: `+`, `-`, `×`, `÷`
- Additional functions: `AC`, `DEL`, `%`, `±`, `.`
- Responsive and mobile-friendly design
- Stylish UI with dark theme

## 📁 Files

- `index.html` – The main structure of the calculator.
- `style.css` – All styles, including button layout and display.
- `app.js` – JavaScript logic for calculator functionality.
